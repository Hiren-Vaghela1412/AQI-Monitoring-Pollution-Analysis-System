# 🌍 AQI Data Analytics & Visualization Project

## 📌 Overview

This project is an end-to-end Air Quality Index (AQI) analytics solution developed using Python, MySQL, Excel, and Power BI. The main objective of this project is to analyze air pollution data, clean and process raw datasets, perform SQL-based analytics, and create interactive dashboards for better environmental insights.

The project covers the complete data analytics workflow starting from raw data storage to visualization and reporting.

---

# 🚀 Objectives

- Store AQI datasets in a structured database
- Extract and process AQI data using Python
- Clean and standardize pollution-related data
- Perform advanced SQL analytics
- Generate insights through visualizations
- Build interactive dashboards in Excel and Power BI

# 📂 Project Workflow

## 🔹 1. Data Storage in MySQL

- Imported AQI dataset into MySQL database
- Verified missing values and duplicates
- Maintained raw dataset for auditing purposes

---

## 🔹 2. Data Extraction using Python

- Connected Python with MySQL database
- Extracted AQI data for processing
- Validated row counts and dataset consistency

---

## 🔹 3. Data Cleaning & Transformation

### Operations Performed

- Handled missing pollutant values
- Standardized city names
- Cleaned AQI category labels
- Removed invalid entries
- Created derived columns for analysis

### Additional Features

- Monthly AQI calculations
- Seasonal categorization
- Pollutant ratio analysis
